# ProTask - Professional Task Management Dashboard

## Overview
ProTask is a professional, interactive task management dashboard built using Vanilla JavaScript (ES6+), HTML5, and CSS3.

## How to Run
1. Unzip the submission folder `Pro_Task.zip`.
2. Open `index.html` in any modern web browser.

## Implemented Features & JS Concepts
- **Validation**: Rejects whitespace titles, past due dates on creation, and duplicate titles.
- **Data Modeling**: Tasks stored as structured JS objects.
- **Array Methods**: Used `forEach()`, `map()`, `filter()`, `find()`, `some()`, `reduce()`, and non-mutating `sort()`.
- **Event Delegation**: Efficient handling of dynamic task Edit, Delete, and Complete actions.
- **Dashboard Analytics**: Real-time stats calculation using `reduce()`.
- **Architecture**: Modular structure separating Data Logic (`Service.js`), UI Logic (`Ui.js`), and App Control (`App.js`).
